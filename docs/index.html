Tiny text animation utility

Reveal every line exactly when it matters.

A focused TypeScript library for smooth, accessible, line-by-line text reveals in static websites. Scroll to compare a small set of practical configurations.

Default configuration

duration 0.85s
delay 0s
stagger 0.1s
distance 115%
start 86%
ease power3.out
initially visible false

Motion is automatically skipped when the visitor requests reduced motion.

01 / DEFAULT
duration 0.85 stagger 0.1 start 86

Balanced by default

A quiet entrance that lets the words keep all the attention.

The default timing is designed for headings with two to four naturally wrapped lines.

02 / SLOW
duration 1.5 stagger 0.14

Editorial pacing

Some thoughts deserve enough time to arrive with intention.

03 / DELAYED
delay 0.55 duration 0.85

Pause after entering

First the space settles. Then the message steps into view.

Delay begins only after the heading reaches its configured viewport position.

04 / COMPACT
duration 0.65 stagger 0.035 distance 75

Fast and compact

Quick rhythm for dense pages and smaller interface moments.

05 / DEEP
distance 180 start 72 expo.out

Greater movement

A stronger rise makes a decisive statement without adding noise.

06 / SOFT
distance 55 duration 1.2 power2.out

Subtle movement

The smallest motion can still give a page a sense of life.

One function. No lifecycle API.

import { scrollTextReveal } from "scroll-text-reveal";

scrollTextReveal("[data-reveal]", {
  duration: 0.9,
  delay: 0.15,
  stagger: 0.08,
});
