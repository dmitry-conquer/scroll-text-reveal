A focused line-by-line text reveal for static websites. The first example can be replayed; the second waits until it reaches the viewport.

01 / Default reveal
duration 0.85 stagger 0.1 start 86

Balanced by default

A quiet entrance that lets the words keep all the attention.

The default timing is designed for headings with two to four naturally wrapped lines.

Continue scrolling
02 / On scroll
default options demo replay

Triggered by position

The next message arrives only when the page brings it into view.

This demo starts a fresh reveal whenever the heading enters the viewport.

03 / Setup

Install once. Reveal any heading with one function.

# Install the library and its GSAP peer dependency
npm install scroll-text-reveal gsap

import { scrollTextReveal } from "scroll-text-reveal";

scrollTextReveal("[data-scroll-text-reveal]");
